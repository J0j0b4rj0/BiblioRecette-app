# BiblioRecette

Application Android pour noter ses recettes de cuisine, retrouver ce qu'il faut
acheter et cuisiner pour le bon nombre de personnes.

## Télécharger

👉 **[Télécharger BiblioRecette.apk](https://github.com/J0j0b4rj0/BiblioRecette-app/releases/latest/download/BiblioRecette.apk)**

Ce lien donne toujours la dernière version. Ouvrez-le **depuis le téléphone**.

## Installer (la première fois)

1. Touchez le lien ci-dessus. Le téléphone télécharge le fichier `BiblioRecette.apk`
   (environ 80 Mo, mieux vaut être en Wi-Fi).
2. Ouvrez le fichier téléchargé (dans la notification, ou dans l'application
   **Fichiers** → **Téléchargements**).
3. Le téléphone affiche peut-être : « Pour des raisons de sécurité, votre téléphone n'est
   pas autorisé à installer des applications inconnues provenant de cette source ».
   C'est normal : l'application ne vient pas du Play Store.
   - Touchez **Paramètres**.
   - Activez **Autoriser cette source** (ou **Autoriser depuis cette source**).
   - Revenez en arrière, puis touchez **Installer**.
4. Si Google Play Protect affiche « Application inconnue » ou « Application non sécurisée »,
   touchez **Plus de détails**, puis **Installer quand même**.
5. Ouvrez **BiblioRecette**.
   - Nouveau : touchez **Créer ma bibliothèque**, puis **notez votre code de récupération**
     (sur papier, ou dans un gestionnaire de mots de passe). Sans lui, vous ne pourrez pas
     retrouver vos recettes si vous changez de téléphone.
   - Vous aviez déjà un compte : touchez **J'ai déjà un compte** (voir plus bas).

Une fois l'application installée, vous pouvez désactiver « Autoriser cette source » si vous
le souhaitez ; il faudra la réactiver pour chaque mise à jour.

## Mettre à jour

Quand une nouvelle version sort, l'écran d'accueil de l'application affiche
« Nouvelle version … disponible ». Touchez **Télécharger**, ouvrez le fichier, puis touchez
**Mettre à jour**. Vos recettes et votre compte restent : rien à refaire.

Vous pouvez aussi, à tout moment, rouvrir le lien de téléchargement ci-dessus.

## ⚠️ Changement de signature : une seule fois, pour ceux qui avaient déjà l'application

Si vous aviez une version de BiblioRecette installée **avant celle-ci** (reçue directement,
pas depuis cette page), le téléphone refusera la mise à jour (« Application non installée »
ou « conflit avec un package existant »). C'est normal : les versions publiées ici sont
signées avec une nouvelle clé. Il faut, **une seule fois** :

1. **Avant tout, retrouvez votre code de récupération** (20 caractères, comme
   `ABCDE-FGHIJ-KLMNO-PQRST`) : dans l'ancienne application, **Paramètres** (roue dentée en
   haut à droite de l'accueil) → **Gérer mon compte** → **Afficher**. Notez-le.
   Si vous avez ajouté un **e-mail de secours**, il peut servir à la place.
2. Désinstallez l'ancienne application : appui long sur l'icône BiblioRecette →
   **Désinstaller** (ou Paramètres du téléphone → Applications → BiblioRecette →
   Désinstaller).
3. Installez la nouvelle version (voir « Installer » plus haut).
4. Ouvrez-la et touchez **J'ai déjà un compte**, puis :
   - saisissez votre **code de récupération**,
   - ou choisissez **Recevoir un code par e-mail** si vous avez un e-mail de secours.

Vos recettes, saveurs, ingrédients et matériel sont conservés : ils sont sur le serveur.
Seuls la **liste de courses** et les **réglages** (thème, couleur, unités) sont à refaire.

Les mises à jour suivantes se feront normalement, sans désinstaller.

## Un souci ?

- **« Application non installée »** : voir « Changement de signature » ci-dessus.
- **Code de récupération perdu, sans e-mail de secours** : contactez la personne qui vous a
  donné l'application ; elle peut vous aider à retrouver votre bibliothèque.
- Cette application ne fonctionne que sur **Android**.
